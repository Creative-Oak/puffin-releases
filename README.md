# Puffin

A toolbox for your Nextcloud: Mail, Calendar, Talk and Files in one fast, quiet,
native window. Mail goes straight to your mail host over IMAP and SMTP; the
calendar, Talk and Files go to your Nextcloud. Nothing to install on the server.

## Download

**[Download the latest version](https://github.com/Creative-Oak/puffin-releases/releases/latest)** (the `.dmg` file),
open it and drag Puffin to Applications. Puffin updates itself after that.

Requires macOS 15 or later. Puffin is signed by Creative Oak and notarized by Apple.
